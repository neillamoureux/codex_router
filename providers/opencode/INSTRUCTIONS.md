# Model Router Instructions for OpenCode

Follow `docs/provider-neutral-policy.md`. Classify each engineering task as
SIMPLE, NORMAL, or COMPLEX, then select the primary, standard, or advanced
lane. Use `docs/handoff-protocol.md` for all delegated work and transfers.

OpenCode installations and configured providers may expose different agent and
session capabilities. Use native named agents only when they are available and
verified. Otherwise keep one implementation owner in the current session,
paste the handoff content when continuing, and disclose that degradation.

Validate with `docs/validation-matrix.md`. Report the lane, provider/model
profile if known, changed files, checks, and remaining uncertainty.
