# Install on Copilot

Add [INSTRUCTIONS.md](INSTRUCTIONS.md) to the target project's Copilot
instruction mechanism (for example, the repository instruction file supported
by the selected editor), following that host's documented precedence rules.
Do not overwrite existing instructions; merge the policy deliberately.

Keep the shared `docs/` directory in the repository. Configure model or agent
choices in the Copilot host rather than hard-coding them in this package.
